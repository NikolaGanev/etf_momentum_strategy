# ETF Momentum Strategy Research

This project explores an ETF momentum strategy using historical market data. The goal is to understand how trend signals, volatility, and rebalancing can be used to support investment-related decision-making.

## Project Overview

The strategy focuses on analyzing ETF price data and testing whether momentum-based signals can help identify stronger-performing assets over time.

## Main Features

- Historical ETF price data analysis
- Momentum signal calculation
- Volatility-based analysis
- Weekly rebalancing logic
- Performance comparison and visualization
